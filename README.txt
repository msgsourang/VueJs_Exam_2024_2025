Examen Vue.js - Massourang Sourang L3CDSD

- Lancer l'application

1. Ouvrir un terminal dans le dossier du projet

2. Installer les dépendances (à faire uniquement la première fois) :

   npm install
   ou
   yarn install

3. Démarrer l'application :
   npm run dev
   ou
   yarn dev

4. Ouvrir le navigateur et aller à l'adresse : http://localhost:8080

- Naviguer dans l'application

- Menu principal (barre latérale)
- Tableau de bord : Vue d'ensemble des revenus et commandes en cours
- Commandes : Gestion des commandes en cours
- Historique : Consultation de toutes les commandes passées
- Comptabilité : Suivi des revenus et transactions
- Rapports : Génération de rapports et analyses

- Fonctionnalités principales

1. Créer une nouvelle commande
   - Cliquer sur le bouton "Nouvelle commande" en haut à droite
   - Remplir les informations du client
   - Ajouter les articles commandés
   - Définir le montant total
   - Valider la commande

2. Gérer les commandes en cours
   - Accéder à la page "Commandes"
   - Utiliser les boutons "Terminer" ou "Annuler" pour changer le statut
   - Cliquer sur "Détails" pour voir les informations complètes

3. Consulter l'historique
   - Accéder à la page "Historique"
   - Utiliser les filtres pour affiner la recherche (statut, période, etc.)
   - Cliquer sur une commande pour voir les détails

4. Générer des rapports
   - Accéder à la page "Rapports"
   - Sélectionner le type de rapport souhaité
   - Définir la période si nécessaire
   - Cliquer sur "Générer le rapport"

-   Remarques

- Il y a des données fictives de test
- Les modifications sont temporaires et seront réinitialisées au redémarrage
